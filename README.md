Интерактивная обучающая платформа, разработанная специально для студентки **breashee** (кампус Школы 21, рабочая станция `er-d9`, проект D03T03 «Управляющие конструкции в C») для глубокого закрепления материала и подготовки к peer-review и экзаменам без слепого копирования.

## 🗺 Структура платформы

### 1. Главная страница и Карта прогресса
- Интерактивный роадмап из **4 модулей и 12 уроков**
- Автоматический трекинг прогресса (сохранение в `localStorage`)
- Раздел засчитывается пройденным, когда:
  - Все упражнения отмечены «решила сама»
  - **ИЛИ** тест урока пройден на **80%+**
- Счётчик XP (очков опыта), серия дней активности (Streak 🔥), индикаторы статусов уроков.

### 2. 12 Уроков в 4 Модулях:
1. **Модуль 1: Терминал Linux и Инструменты**
   - Урок 1: Навигация и файловая система в Linux (`pwd`, `ls -la`, `cd`, `mkdir -p`, `cp`, `rm -rf`, `cat`)
   - Урок 2: Потоки ввода-вывода, пайпы и фильтрация (`|`, `>`, `>>`, `head`, `tail`, `wc -l`, `sed -n`)
   - Урок 3: Компилятор GCC и автоформатирование (`gcc -Wall -Wextra -Werror -std=c11 -lm`, `clang-format -n -i`)
2. **Модуль 2: Git и Версионирование**
   - Урок 4: Основы Git и рабочий цикл Школы 21 (`clone`, `status`, `add`, `commit`, `push`, аналогия коробка-посылка)
   - Урок 5: Ветки, история и спасение кода через `git restore` (`checkout -b develop`, `git diff`, `git log`)
   - Урок 6: Чистота репозитория и типичные ловушки (запрет бинарников в Git, `.gitignore`, unpushed commits)
3. **Модуль 3: Основы языка C и Стандарты**
   - Урок 7: Базовые типы данных, переменные и ввод-вывод (`int`, `double`, `char`, `long long`, `%lld`, `%02X`)
   - Урок 8: Строгая валидация ввода и обработка ошибок (`scanf != 1`, `tail_is_clean()`, вывод `n/a`, правило Дейкстры)
   - Урок 9: Управляющие конструкции и циклы (`if/else`, `while`, `for`, запрет `goto`, накопление результата)
4. **Модуль 4: Продвинутый C и Алгоритмы Школы 21**
   - Урок 10: Указатели и выходные параметры функций (`&`, `*`, возврат нескольких значений, деление вычитанием)
   - Урок 11: Алгоритмы делимости и простые множители (методика «Кирпичики», ловушки квадратов 9/25/49, разбор 91, 100, 32)
   - Урок 12: Hex/ASCII, Рекурсия и Указатели на функции (`getchar()`, `hex_value()`, `fibonacci`, стек вызовов, сетка 2π/41, указатели на функции)

## 🔒 Механика каждого упражнения (Anti-Copy Mechanics)

1. **Условие задачи:** Чёткая постановка с форматом ввода-вывода и стандартами Школы 21.
2. **Кнопка «Подсказка»:** Показывает направление мысли и псевдокод без спойлеров решения.
3. **Редактор ввода с «правильным» Enter:**
   - `Enter` — переход на новую строку с авто-отступом (можно печатать цепочку команд по одной на строку);
   - экранные «клавиши» `⏎ Enter` / `Tab` кликабельны мышью;
   - `Tab` / `Shift+Tab` — отступ блока, `{`, `(`, `"` — автопара;
   - `Ctrl+Enter` — проверить, `Alt+Enter` — перепрыгнуть к следующему упражнению (или к тесту).
4. **Живая подсветка ответа (не надо жать «Проверить»):**
   - 🟢 зелёный — всё на месте; 🟡 янтарный — не дописано (показаны недостающие токены); 🔴 красный — ошибка;
   - для команд: несопоставимая/несуществующая команда, опечатки (`gti` → `git`), `rm -rf /`, количество команд;
   - для C: незакрытые скобки, отсутствующий `;`, `main`, `#include`, `goto`, форматные спецификаторы и обязательные конструкции.
5. **Кнопка «Показать решение»:** **ЗАБЛОКИРОВАНА** до тех пор, пока пользователь не поставит галочку *"Я попробовал(а) сама"*.
6. **Эталонное решение:** Подсветка синтаксиса с подробным **построчным разбором каждого шага** и комментарием к стандарту Школы 21.

## ⌨️ Вкладка «Команды» — полные цепочки по квестам

Отдельная вкладка со справочником «хочу сделать квест — печатаю по порядку»:

- **0. Подготовка станка** (ключ → клон → `develop` → структура папок);
- **1–7. Каждый квест Дня 2** от `touch src/hello.c` до `git push origin develop`, включая проверку вывода (`cat -A`, `| wc -c`, `diff`) и уборку бинарников;
- **8. Git-цикл дня**, **9. Сборка/стиль/чистота**, **10. Отладка**, **11. Ритуал экзаменационного дня**.

Каждая команда — кнопка копирования в один клик, есть «скопировать всё», поиск по вкладке, блоки «грабли» и ссылка на соответствующий урок.

## ⏱ Симулятор экзамена (10 задач на время)
- Таймер обратного отсчёта на 45 минут (с возможностью паузы) либо спокойный режим без таймера.
- 10 практических и теоретических задач (валидация `double_it`, простые множители 91 и 100, откат в Git, флаги GCC, деление вычитанием через указатель, HEX декодирование, стек рекурсии, шаг сетки 2π/41, правило Дейкстры).
- **Подсказка у каждой задачи** — кнопка в шапке карточки, не спойлерит решение.
- **Живая подсветка по мере ввода** + кнопка «Проверить эту задачу»; та же логика проверки, что и при итоговом подсчёте баллов (никаких расхождений).
- Вверху — номера задач со «светодиодами»: зелёный (зачтено), жёлтый (не дописано), красный (ошибка), серый (пусто).
- `Ctrl+Enter` — проверить и перейти к следующей задаче; `Enter` — новая строка в коде.
- Детальный отчёт: твой ответ, эталонный код, что именно не хватило, пояснение.

## 🗂 Словарь команд (60 карточек) + режим «Свайп»
- Классические карточки: клик/пробел — перевернуть, стрелки — листать, отметка «Знаю», шкала освоения.
- **Режим знакомств (свайп):** слева термин (`git status`, `ls -la`, `epsilon`), справа — определение.
  - свайп **вправо** = «это правильная пара», **влево** = «перепутано» (работают и кнопки, и ← / →);
  - большой **зелёный индикатор** за верное решение и **красный** за ошибку, лента точек-результатов, серия (streak) и рекорд;
  - после ошибки сразу показывается правильное значение термина; вердикты попадают в прогресс (+XP, статусы карточек).
- Категории: *Bash, Git, GCC/Clang, Концепции* + поиск по всему словарю.

## 🎨 Стиль
Сайт намеренно сделан «проще»: плоские карточки без теней и градиентов, аккуратные тонкие рамки,

## 🧱 Интерактивные тренажёры и виджеты
- **Дрилл «Кирпичики»:** Специальный тренажёр для отработки разложения на простые множители и ловушек квадратов (9, 25, 49, 98, 75, 55, 45, 91, 100, 32).
- **Виртуальный терминал кампуса `er-d9`:** Поддержка команд Linux, сборки GCC, проверки clang-format и git.
- **Hex ↔ ASCII декодер:** Перевод hex-последовательностей с пасхалками (`HELLOwORLD`, `FIBONACCI21`).
- **Визуализатор дерева рекурсии:** Дерево вызовов Fibonacci и демонстрация переполнения стека без базового случая.
- **Калькулятор сетки графиков:** Интерактивная демонстрация правила интервалов (42 точки = 41 щель).
